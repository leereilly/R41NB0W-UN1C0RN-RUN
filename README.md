# Rainbow Unicorn Run

A browser game about flying a unicorn through a neon tunnel. Collect rings in rainbow order, from red to purple. Wrong colors cost a heart; three mistakes end the run.

Open `index.html` in a modern browser. No build step. Requires an internet connection to load Three.js.

## Controls

- Mouse, WASD, or arrow keys to steer.
- Space or **Start** to play.

WebXR VR is supported on compatible browsers and headsets when served over HTTPS or localhost. Select **Enter VR**, then look to steer. Look at the circular target to start or restart.
